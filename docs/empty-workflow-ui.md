# Empty Practice and Pro Creation

Both modes are UI session shells. Their workflows and executable steps are empty.
The existing file selection/drop zones, Edit Type setup and selection, Proceed to
 do homework / Create pro edit buttons, session persistence and Cancel remain.

Starting saves only the selected input paths and Edit Type under `ui-sessions.json`.
No assignment is available to a GPT worker. No queue, Source Match, learned recipe,
research, AE operation, render, Supervisor or automatic chat is started or resumed.
Old production endpoints return `410 WORKFLOW_NOT_CONFIGURED`.

Edit Type names remain; all prior examples, lessons, skills and session learning
are cleared. The old workflow implementations and Supervisor scripts are removed.
A new process must be designed explicitly with the user before any editing can run.
