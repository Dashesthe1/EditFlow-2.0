# Current production direction

ChatGPT direct editorial authority replaces the retired creative decision engines.
Footage matching/ranking, effect synthesis/correction, tutorial compilers, machine
certification, formula curves and local-model decision drivers are deleted.

Continue improving explicit native AE operation coverage, robust queue execution,
requested footage inspection and evidence-backed preset worked examples. Native
tracking, segmentation and roto execute only ChatGPT-chosen targets and settings.
Historical acceptance evidence remains as provenance, without reviving deleted engines.

See [current policy](chatgpt-editorial-authority.md).
