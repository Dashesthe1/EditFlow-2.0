# Production implementation

The active path is durable assignment → production-jobs → single AE writer → explicit
native execution → retained render/readback → ChatGPT review and preset notebook.

ChatGPT decides the plan and exact editing values. The host validates capabilities,
revision, filesystem scope and rollback boundaries. Queue admission and the host reject
retired nested formula directives. Legacy creative engines and alternate production
entry points are physically deleted; clean builds cannot leave their emitted JS behind.

Per-clip research retains ChatGPT-reviewed tutorial/Adobe/web methods and explicit
adaptations. No compiler derives the construction. The notebook keeps reproducible
worked and failed examples in the existing preset record.

Use npm run check for schema, type and retained execution tests. Native adapter tests
verify mechanical operations; they never choose production edits. See
[current production policy](chatgpt-editorial-authority.md).
