# ADR 0000 — Architecture Decision Record Process

- Status: Accepted
- Date: 2026-09-05

## Decision
Material architecture decisions are recorded in `docs/adr/` before the dependent implementation is merged.

Each ADR records context, decision, alternatives, consequences, human-parity impact, safety/rollback impact, and proof impact. Superseded decisions remain in history and point to the replacement ADR.

## Consequence
Host integration, stable identity, persistence, proof formats, and UI fallback cannot become undocumented implementation accidents.
