# Mandatory clip research during production

Practice and Pro Creation previously advertised tutorial-first research while ordinary AE actions could bypass it. Production now requires a durable research plan for each affected clip before editing through the integrated product service or Current Shadow control routes.

The sequence is assignment discovery/resume and connection preflight, raw/reference clip inspection, Tutorial Drive consultation, source-derived method selection, footage-specific adaptation, AE construction, and the existing M6 render/reference fidelity loop. Source fallback is Tutorial Drive, official Adobe documentation, then online sources. Escalation requires a recorded no-match or partial result with a specific uncovered behavior; unavailable access is a repair condition.

`GET /v1/product/gpt/clip-research-contract` describes the payloads. `GET/POST /v1/product/gpt/assignments/{id}/clip-research` resumes/records SCAN, SOURCE and PLAN. Consulted sources retain their query, URI, title, time/section, observations or search result artifact, content hash, AE tools and method steps. Matched tutorial sources must reference a compiler-backed RESEARCH source from the existing tutorial-compilations route. A tutorial name, ET prior or precompiled-policy flag cannot unlock editing.

Plans bind every scanned effect to consulted source steps, an adaptation for the provided raw footage, and explicit comparison checks. Editing requests carry `researchContext` with assignment ID, live controller owner, and affected clip/plan IDs. Baseline assembly covers all matched clips. Declared clip/shot targets must have plans; arbitrary JSX remains an opaque execution route whose complete target set is the controller's responsibility. Research gates do not prove that a script implements its method correctly: real AE readback and rendered visual fidelity remain authoritative.

The ledger lives beside the durable GPT assignment store and uses serialized atomic replacement. Plan reuse survives chats and service restarts. Changed scans, inspected/reviewed artifacts or assignment source bindings invalidate prior admission. Identical scans and source reposts preserve completed research. Admission is recorded before dispatch; HTTP completion/failure is recorded afterward without claiming visual correctness. Cancellation and GET inspection remain available.

Existing MCP schemas remain usable: `fast_ae_run` accepts a `{goal,researchContext}` JSON envelope; `fast_ae_batch` accepts `{intents,researchContext}`; `apply_edit_plan` forwards `decision_json.researchContext`. New research tools also expose the ledger/contract. Controllers can use the authenticated product API if their cached tool catalog predates these additions.

This change introduces no automatic edit pass, skill promotion, reference media reuse, assignment restart or AE shutdown. ChatGPT directly analyzes tutorial methods and final render fidelity; retired compiler and M6 gates are deleted. Implementation tests cover omitted gates, ordered fallbacks, directly reviewed source provenance, raw-only inspection, plan binding, artifact invalidation, restart continuity, controller ownership, cancellation, both production modes, HTTP routing and MCP envelope forwarding.
