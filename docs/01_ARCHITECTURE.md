# Architecture

Practice and Pro Creation use the durable assignment and production queue. ChatGPT
inspects the actual reference, raw footage and renders. It chooses exact shots, audio,
timing, effects, transitions, keyframes, corrections and final PASS/REVISE.

The production worker owns scheduling, the single AE writer, revision checks, rollback,
checkpoints and retained receipts. Native adapters apply explicit properties and execute
ChatGPT-chosen tracking/roto targets, methods and settings. Mechanical observations do
not nominate footage, choose an effect, change parameters or decide final acceptance.

Every queued job binds an immutable editorial decision to its exact payload. ChatGPT
records per-clip research plans and declared dependencies. Broad changes after whole-edit
coverage require an explicit global declaration; affected proof is invalidated while
unrelated completed work is retained.

The selected preset’s existing gptLearning notebook retains reviewed successes, failures,
ordered steps, exact settings, reasons, checks and adaptation guidance. ChatGPT retrieves
and interprets it on each start/resume; no automatic recipe selection or promotion runs.

Retired creative engines, machine certification, formula curves and local-model decision
drivers are deleted. Only historical data shapes and evidence remain. Clean runtime
builds remove stale emitted files. See [the production contract](chatgpt-editorial-authority.md).
